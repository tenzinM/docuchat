# docuchat 
Chat with your PDFs — fully local, fully free, fully cited.

Local, citation-grounded RAG app for chatting with your PDFs — FastAPI + React, running entirely on free open-source models (Ollama, sentence-transformers, ChromaDB). No API keys, no cost. Includes a RAGAS evaluation harness to actually measure retrieval/answer quality, not just demo it.

Topics: rag llm python fastapi react ollama chromadb sentence-transformers vector-search ragas document-qa local-llm
